# Защита основного редактора синхронизации

Codex IAB, 2026-10-27. Настоящий RepositorySyncEditor и Base UnsavedChangesGuard,
owner i18n, Data Router и локальный синтетический transport. Сохранение
подтверждается таймером, реальные API, Auth и установленные стенды не используются.

- [Dark, 375 px](guard-dark-375.png).
- [Gray, 1920 px](guard-gray-1920.png).
- [Light, 2560 px](guard-light-2560.png).

Указана дважды проверенная фактическая ширина iframe. Внешний canvas может быть
шире мобильной сцены; белая область вне iframe относится к QA-документу.
Три full-page снимка просмотрены. Для трёх тем и четырёх ширин проверены
отсутствие overflow, Enter/Escape, сохранность ввода, возврат focus и уход
после подтверждения. Отдельно проверены один синтетический save при открытом
диалоге и продолжение исходного перехода; standalone-пример Base проверяет
отмену и сохранение более новой версии после позднего ответа.

Финальные fixtures и исходники сохранили hashes; продуктовых запросов не было.
Fixture не входит в production-поставку. Это не backend-квалификация
синхронизации или runtime-приёмка.
