# Internationalization (i18n) — Forge CI/CD

## 1. Overview

Приложение поддерживает русский (`ru`) и английский (`en`) языки. **По умолчанию — русский.** Локаль пользователя сохраняется в `localStorage`.

## 2. Libraries

| Библиотека | Версия | Назначение |
|-----------|--------|------------|
| `i18next` | 25.1.0 | Ядро i18n |
| `react-i18next` | 15.5.0 | React-интеграция (`useTranslation`) |
| `i18next-http-backend` | 3.0.2 | Загрузка локалей по HTTP (опционально) |

## 3. Supported Locales

| Locale | Language | Fallback | Default |
|--------|----------|----------|---------|
| `ru` | Русский | `en` | ✅ да |
| `en` | English | — | — |

## 4. Configuration

```ts
// frontend/src/shared/i18n/config.ts
import i18n from 'i18next'
import { initReactI18next } from 'react-i18next'
import en from './locales/en.json'
import ru from './locales/ru.json'

i18n.use(initReactI18next).init({
  resources: {
    en: { translation: en },
    ru: { translation: ru },
  },
  lng: 'ru',
  fallbackLng: 'en',
  interpolation: { escapeValue: false },
  react: { useSuspense: false },
})

export default i18n
```

### Параметры

| Параметр | Значение | Описание |
|----------|----------|----------|
| `lng` | `'ru'` | Язык по умолчанию |
| `fallbackLng` | `'en'` | Язык при отсутствии ключа |
| `interpolation.escapeValue` | `false` | React сам экранирует значения |
| `react.useSuspense` | `false` | Не блокировать рендер при загрузке локалей |

## 5. Locale Files Structure

```
frontend/src/shared/i18n/
├── config.ts          # i18next конфигурация
└── locales/
    ├── ru.json        # Русская локаль (default)
    └── en.json        # Английская локаль
```

Локали загружаются синхронно через `import` — отдельной HTTP-загрузки не требуется в текущей версии.

## 6. Key Structure

Ключи организованы по доменам (namespaces внутри единого `translation` namespace):

```json
{
  "app": { "name": "Forge CI/CD" },
  "navigation": { "dashboard": "...", "projects": "...", "pipelines": "..." },
  "projects": { "title": "...", "create": "...", "name": "...", "empty": "..." },
  "pipelines": { "title": "...", "run": "...", "queued": "...", "running": "..." },
  "jobs": { "start": "...", "pass": "...", "fail": "...", "logs": "..." },
  "stages": { "build": "...", "test": "...", "deploy": "..." },
  "common": { "save": "...", "cancel": "...", "loading": "...", "error": "..." }
}
```

### Домены

| Домен | Содержание |
|-------|------------|
| `app` | Название приложения |
| `navigation` | Навигация, меню |
| `projects` | Проекты: поля, действия, сообщения |
| `pipelines` | Пайплайны: статусы, поля, действия |
| `jobs` | Задачи: действия, поля |
| `stages` | Стадии: названия по умолчанию |
| `common` | Общие кнопки, сообщения, состояния |

## 8. Usage in React

```tsx
import { useTranslation } from 'react-i18next'

export function ProjectsPage() {
  const { t } = useTranslation()

  return (
    <div>
      <h1>{t('projects.title')}</h1>
      <p>{t('projects.empty')}</p>
      <button>{t('projects.create')}</button>
    </div>
  )
}
```

### 8.1 Доступ к вложенным ключам

```tsx
t('navigation.dashboard')    // "Дашборд"
t('pipelines.queued')        // "В очереди"
t('jobs.start')              // "Запустить"
t('common.loading')          // "Загрузка…"
```

### 8.2 Использование в виджетах

```tsx
// widgets/app-shell.tsx
import { useTranslation } from 'react-i18next'

export function AppShell() {
  const { t } = useTranslation()
  // ...
  <NavLink to="/projects">{t('navigation.projects')}</NavLink>
}
```

## 11. Locale Switching

```tsx
import { useTranslation } from 'react-i18next'

function LocaleSwitcher() {
  const { i18n } = useTranslation()

  const changeLocale = (lng: 'ru' | 'en') => {
    i18n.changeLanguage(lng)
    localStorage.setItem('locale', lng)
  }

  return (
    <div className="flex gap-2">
      <button onClick={() => changeLocale('ru')}>RU</button>
      <button onClick={() => changeLocale('en')}>EN</button>
    </div>
  )
}
```

## 12. Добавление новых ключей

### 12.1 Процедура

1. Определить домен (`projects`, `pipelines`, `jobs`, `common`, ...).
2. Добавить ключ в `ru.json` (основной язык).
3. Добавить тот же ключ в `en.json` (fallback язык).
4. Использовать в компоненте: `t('domain.key')`.
5. Проверить: переключить язык, убедиться что текст меняется.

### 12.2 Правила

- Ключи в camelCase: `repositoryUrl`, `defaultBranch`, `toggleMenu`.
- Вложенность не более 2 уровней: `domain.section.key` (не глубже).
- Общие термины — в `common`, не дублировать в доменах.
- Статусы (`queued`, `running`, ...) — в соответствующем домене (`pipelines`).
- Если ключ нужен в нескольких доменах — вынести в `common`.

### 12.3 Пример

Добавление ключа для кнопки «Удалить проект»:

```json
// ru.json
{
  "projects": {
    "delete": "Удалить проект",
    "deleteConfirm": "Вы уверены? Действие необратимо."
  }
}

// en.json
{
  "projects": {
    "delete": "Delete project",
    "deleteConfirm": "Are you sure? This action cannot be undone."
  }
}
```

```tsx
<button onClick={handleDelete}>{t('projects.delete')}</button>
```

## 13. Date / Number Formatting

```tsx
import { format } from 'date-fns'
import { ru } from 'date-fns/locale'

const localeMap = { ru, en: undefined }
format(date, 'dd MMM yyyy, HH:mm', { locale: localeMap[i18n.language] })
```

При отсутствии `date-fns` — использовать `Intl.DateTimeFormat`:

```tsx
new Intl.DateTimeFormat(i18n.language, {
  dateStyle: 'medium',
  timeStyle: 'short',
}).format(new Date(dateString))
```
