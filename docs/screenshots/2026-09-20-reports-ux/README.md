# Reports UI/UX visual QA

The screenshots show the Reports page with mocked API responses in an isolated
shell. They are visual regression evidence, not proof of live SSO or backend
report behavior. The populated view was captured at 375, 1920 and 2560 pixels;
empty and error states were captured at 375 pixels. All images use the light
theme. The browser QA also covered 320, 375, 768, 1280, 1920 and 2560 pixels,
all three themes, and all three states.
