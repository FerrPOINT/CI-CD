# Проверка UI секретов проекта

На снимках показан настоящий компонент Secrets с общими токенами тем и рабочей областью той же ширины, что в app shell. Временный браузерный стенд подставил 25 синтетических записей метаданных. GET был замокирован; POST и DELETE перехвачены с намеренным ответом 500. Живые секреты и данные проектов не изменялись.

В Chromium проверены ширины 320, 375, 768, 1280, 1920 и 2560 px в тёмной теме; на 375 px также светлая и серая темы. Проверены фокус при замене, ошибка создания и ошибка удаления. На всех ширинах списка нет горизонтального переполнения, целей меньше 40 px и серьёзных/критических нарушений axe. Диалог удаления помещается в viewport 320/375 px, сохраняет видимую ошибку и имеет действия высотой 40 px. Два сообщения 500 в `qa.json` соответствуют намеренным ошибкам мутаций.

Это браузерная проверка компонента с подменёнными ответами, а не приёмка на развёрнутом API и SSO shell. Живая интеграционная проверка остаётся условием релиза.
