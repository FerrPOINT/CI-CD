# Свидетельства проверки пагинации pull-запросов

Production-сборка фронтенда по адресу `http://localhost:7712` проверена с реальной SSO-сессией и детерминированными read-only API-фикстурами.

## Покрытие

- Матрица списка: светлая, серая и тёмная темы на ширинах 375, 768, 1280, 1920 и 2560 px.
- Плотный набор данных: 53 pull-запроса, по 20 строк на серверной странице.
- Взаимодействия: переход на вторую страницу, поиск с задержкой, фильтр статуса, сохранение фильтра после перезагрузки, форма создания и прямой переход к PR.
- Подсказки ссылок: предлагаются только ветки; теги и прочие ссылки исключены; ручной ввод сохранён.
- Runtime-проверки: нет горизонтального переполнения, слишком маленьких или безымянных проверяемых элементов управления, ошибок браузера, неуспешных ответов приложения и API-мутаций.
- Доступность: на проверенных экранах списка и деталей нет серьёзных или критических нарушений axe.

Машиночитаемые измерения и журнал запросов находятся в [`results.json`](results.json).

## Ключевые снимки

- `list-light-375.png`: компактный мобильный список.
- `list-dark-1920.png`: плотный список на desktop.
- `interaction-page-2-light-375.png`: вторая серверная страница.
- `interaction-filter-closed-light-375.png`: сохранённый фильтр статуса.
- `interaction-create-form-light-375.png`: форма с подсказками только для веток.
- `interaction-detail-light-1280.png`: прямой запрос страницы деталей.

Все запросы браузерной проверки были read-only. Зафиксированный массив `mutations` пуст.
