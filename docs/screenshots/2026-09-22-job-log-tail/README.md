# Job log tail QA

Проверка выполнена 2026-09-22 в Chromium на production-сборке Dashboard.
Использованы реальные Central Auth и платформа; ответы pipeline detail, attempts,
test report и log pages перехвачены в браузере детерминированными данными на 501
строку без изменений backend.

Проверено:

- начальный запрос `before=2147483647` открывает последние 200 строк;
- ранние окна загружаются курсором `before` и остаются в хронологическом порядке;
- live-обновление сохраняет позицию читателя и предлагает переход к свежему выводу;
- поиск использует независимый прямой курсор `after=0`;
- desktop 1440x900, wide 1920x1080/2560x1440 и mobile 375x812 не имеют
  горизонтального переполнения;
- единственный вложенный скроллер — фокусируемый `role="log"`;
- нет runtime/network ошибок, малых интерактивных целей и axe-нарушений уровней
  serious/critical.

Артефакты:

- `desktop-latest.png` — последнее окно сразу после открытия;
- `desktop-reader-position.png` — сохранённая позиция и действие перехода вниз;
- `mobile-latest.png` — хвост лога на ширине 375 px;
- `wide-1920.png` и `wide-2560.png` — full-page проверка широких экранов;
- `qa-report.json` — запросы и автоматические проверки.
