# Серверная пагинация журнала аудита

Снимки сделаны 2026-09-22 в Chromium из production-сборки `cicd-web` с
настоящими Central Auth SSO и platform shell. Только ответ нового
`/api/v1/audit-log/page` подменён в браузере детерминированным набором из 47
событий; рабочая база данных не изменялась.

- Проверены темы light, gray и dark на ширинах 375, 768, 1280, 1920 и 2560 px.
- Отдельно сняты вторая страница, фильтр по действию, поиск, отсутствие
  совпадений, HTTP 503 с повтором и защита от некорректного номера страницы.
- `qa-report.json` содержит метрики для 22 состояний.
- Во всех состояниях: 0 горизонтальных переполнений, вложенных областей
  прокрутки, элементов управления меньше 40 px, серьёзных/критических замечаний
  axe и неожиданных ошибок console/network/runtime.

Backend дополнительно проверен полным набором из 57 PostgreSQL integration
tests, включая чтение после 200-й записи, фильтры, общий счётчик и индекс.
