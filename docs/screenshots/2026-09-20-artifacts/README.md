# Проверка каталога артефактов

Снимки сделаны 2026-09-20 в локальном Vite/Chromium со **синтетическими** 26
метаданными файлов. Это проверка интерфейса, а не подтверждение работы
production API, SSO, прав доступа или реального скачивания.

- Размеры: 320, 375, 768, 1920 и 2560 px; темы dark, gray и light.
- `375-light-download-error.png`: ответ скачивания HTTP 500, ошибка показана
  возле конкретного файла.
- `qa.json`: ширина документа, минимальная высота controls, ошибки браузера и
  серьёзные/критические нарушения axe после загрузки каждого экрана.
- Во всех проверенных состояниях нет горизонтального переполнения, высота
  действий от 40 px, ошибок JS и серьёзных/критических замечаний axe.

Поиск, фильтрация, пагинация, копирование SHA-256 и повтор скачивания покрыты
тестами `frontend/src/pages/artifacts/artifacts-ux.test.tsx`.
