# Проверка предпросмотра большого файла

Проверен production build страницы репозитория с текстовым blob размером 37 441 262 байта и ограниченным предпросмотром первых 512 КиБ.

## Матрица

- Ширины: 375, 768, 1280, 1920 и 2560 px.
- Темы: light, gray и dark.
- Всего: 15 сочетаний.
- Авторизация и оболочка приложения: реальные.
- Ответы `refs`, `tree` и `blob`: read-only фикстуры для синтетического репозитория `qa-blob`.

## Результат

- нет горизонтального переполнения страницы;
- нет видимых интерактивных целей меньше 40 px;
- единственный внутренний скролл находится у предпросмотра кода;
- предпросмотр получает клавиатурный фокус;
- отображаются полный размер файла и уведомление об ограничении 512 КиБ;
- нет ошибок выполнения и неуспешных сетевых запросов;
- нет серьёзных или критических нарушений Axe.

Машиночитаемые измерения находятся в `qa-report.json`. Контрольные кадры: `blob-375-light.png`, `blob-1920-gray.png` и `blob-2560-dark.png`.
