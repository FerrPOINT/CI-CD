# Навигация Recruiter

Обновить отдельный UI pin Base и подключить ApplicationAccessProvider к текущей
браузерной сессии. Общий каталог остаётся публичным; переключатель использует
свежий допуск Central Auth. Recruiter виден активному администратору, пока включён.
Недоступный допуск закрывает навигацию; смена аккаунта и logout очищают старое состояние.
Backend и предметные правила соседних сервисов не меняются.

Для совместимости UI обновляются только необходимые зависимости и существующие
потребители нового Select API по опубликованным upstream миграциям Base 0.2.
Проверки: scoped type/lint и три проверки реального provider, включая admin/user,
смену аккаунта, logout, отзыв сессии и недоступность Auth; интегрированная сборка;
фактически установленная навигация через Codex IAB.
Исходный установленный OCI revision записан в navigation-source-baselines.json задачи.
