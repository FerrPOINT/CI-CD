# Реестр рисков — Forge CI/CD

> Реестр фиксирует риски текущего MVP и целевой архитектуры. Статус возможности
> указывается только как `Current verified`, `Configuration only` или `Target approved`;
> он не означает, что риск закрыт.

**Шкала:** `L = 1`, `M = 2`, `H = 3`; **скор** = likelihood x impact. Риск закрывается
> только после реализации mitigation, доказательства проверки и обновления этого реестра.

## Правила ведения

- `Open` — mitigation не начат; `Mitigating` — есть активная работа или временный control; `Accepted` — tech lead письменно принял остаточный риск с датой пересмотра; `Closed` — control реализован и подтверждён evidence.
- Изменение likelihood, impact, owner или статуса требует ссылки на evidence: ADR, контракт, PR/release, результат проверки либо incident record.
- До выполнения target mitigation данный реестр не меняет фактический статус MVP из [CURRENT_STATE](CURRENT_STATE.md).
